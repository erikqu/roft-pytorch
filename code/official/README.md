# Paper assets and author reference

This is a local paper-derived implementation. An official ROFT trainer was not found in the bounded search recorded here; that search cannot prove no repository exists.

`failed_system.txt` and `experimental_setup.tex` are extracted paper source assets from [arXiv 2609.35741v1](https://arxiv.org/abs/2609.35741v1). `paper_provenance.json` records original source/PDF hashes; the full PDF and source archive are retained separately and not included in this Git repository.

`author_mini_swe_agent_default.py` is an author-owned generic mini-swe-agent reference at the commit in `author_scaffold_provenance.json`. It is not imported into this trainer and is not an official ROFT trainer. Its upstream MIT notice is in `author_scaffold_LICENSE.md`.

The repository's MIT license covers the locally authored code. Paper extracts retain the authors' original rights and arXiv distribution terms; the local license does not relicense them.
