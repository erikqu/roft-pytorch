Updated 2026-10-12 18:09 UTC. The earlier v4 audit remains preserved in [METHODOLOGY_AUDIT_20261012.md](PRIOR_METHODOLOGY_AUDIT.md). This table distinguishes repaired defects from remaining adaptations.

| Area | Paper methodology | Earlier experiment's misalignment | Corrected run and remaining limitation |
|---|---|---|---|
| Online training | Fresh attempts and four fresh retrospections as learner weights change; one pass per accepted batch | One real 256,721-token update, with no new attempts from the updated checkpoint; separate historical repetition runs reused targets | **Fixed:** seven saved updates, 112 fresh attempts, 448 fresh reflections, 438 targets used once, no replay. |
| Supervised tokens | All retained thinking, answer and end-of-turn tokens; prompt masked | Random masks omitted 169,442 of 426,163 retained tokens | **Mostly fixed:** 437 whole targets plus one 633/646-token boundary target. Its last 13 answer/EOT tokens remain unsupervised to meet the user's exact 256,721-token cap. Ten unselected fresh targets are preserved. |
| Agent tools | Functional file and shell interaction | Custom action format produced 84.3% malformed observations; a one-byte corrupt output was labelled saved/executed | **Fixed:** native Qwen tool schemas, persistent shell/file tools, qualified real scene execution. File existence cannot establish a valid scene. Model mistakes remain recorded. |
| Reflection context and feedback | Actual task, independently bounded thought/action/observations, patch and raw tests; verdict separate from termination/reward | Verifier rejection reason omitted; execution summary overstated evidence | **Fixed:** original trajectory, script and actual verifier feedback are audited; missing raw binary verdict stays unknown. Reflection instruction adds disclosed Blender-specific evidence cautions. |
| Sampling and episode limits | Solver T=1, reflection T=0.9, top-p=1; 100 turns, 8,192 tokens/turn, 131,072 context; no compaction | One length-limited turn ended an entire episode; context accounting left usable capacity | **Fixed:** these frozen budgets and sampling settings apply; turn, context and output termination are recorded separately. |
| Gradient/optimizer/state | Full-model AdamW, lr=1e-6, betas=(0.9,0.98), eps=1e-8, decay=0.1; token-mean loss ×4; clip=1; no KL/entropy | Native BF16 gradients before FP32 accumulation; incomplete fresh-checkpoint comparison/recovery | **Fixed and audited:** all 723 FP32 parameter tensors changed each update; full Adam/RNG restore, CPU state audits and fresh reloads passed. FP32 parameter storage/CPU Adam are single-H100 adaptations. Update 1's unrecorded pre-clip norm remains missing. |
| Batch and compute | Nominal 64 sources ×4 reflections; four training and four serving B200s; bounded asynchronous policy lag | Single H100, smaller run and serial phase barriers | **Remaining:** 16 sources ×4 per cycle, single H100 with CPU Adam, serialized generation/training and zero lag within each cycle. This cannot demonstrate the paper's wall-time advantage. |
| Dataset and verifier | 767 coding tasks with test outcomes | User-requested Blender tasks and continuous geometry/visual rewards | **Remaining:** frozen 72-task Blender training pool. Uniform, qualified malformed-topology guard routes native verifier crashes to its existing invalid-model path; valid scores match qualification. Both final arms use it. This is not a coding benchmark replication. |
| Evaluation | Separate fresh solver evaluation without reflection text in the inference prompt | Earlier run did not complete a final comparison | **Complete and audited:** 34 fresh ROFT +34 fresh same-model base candidates, each with actual verifier rewards and preserved raw tokens. All 34 paired initial prompts match. ROFT transfer reward 0.0116385 versus base 0.0067806; within-task 0.0117857 versus 0.0075516. Both task-cluster 95% intervals include zero. Interrupted baseline histories resumed original seeds/containers; one lost tool observation remains explicitly unknown. Historical GRPO results are not substituted. |
| Official implementation | Author implementation, if released | No official trainer available in the completed code search | **Remaining:** locally implemented trainer checked against pinned source/prompt. Generic harness reference code is not labelled an official ROFT trainer. |
